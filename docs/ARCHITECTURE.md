# 系统设计与算法说明

本文档补充 README 中省略的设计细节，对应课程报告的"系统总体方案"与"算法原理"两章。

## 1. 三层架构

```
┌──────────────────────────────────────────────────────────────┐
│ 感知层   /scan(360 点) ──分区取最小距离──> front / left / right │
│          /odom(50 Hz)  ──四元数转 yaw──> (x, y, yaw)           │
├──────────────────────────────────────────────────────────────┤
│ 决策层   CellWallFollower（左手法则状态机）                      │
│          DECIDE → TURN → ADVANCE → DECIDE …    出口则 ARRIVED   │
│          输出：目标航向（90° 整数倍）、目标格心坐标               │
├──────────────────────────────────────────────────────────────┤
│ 控制层   角闭环转向（P）／航向保持 + 侧墙居中修正                  │
│          输出：v, ω ──> /cmd_vel ──> Gazebo diff_drive 插件      │
└──────────────────────────────────────────────────────────────┘
```

设计原则：**算法与 ROS 解耦**。`maze_mouse_core.py` 完全不 import rclpy，因此

1. 可用 `python3 -c` 直接单测；
2. 可被离线几何校验工具调用（numpy 做 360 线射线求交，3 秒跑完全程，用于快速调参）；
3. 报告里能单独讲算法，不被 ROS 代码淹没。

## 2. 坐标与几何约定

| 量 | 取值 | 说明 |
| --- | --- | --- |
| 格距 `pitch` | 0.66 m | = 通道 0.60 + 墙厚 0.06 |
| 格心世界坐标 | `(0.33 + 0.66·col, 0.33 + 0.66·row)` | row 0 在南、col 0 在西 |
| 迷宫外框 | x, y ∈ [0, 3.30] | 5 × 0.66 |
| 出生点 | 世界系 (−0.33, 0.33) | 入口外的"出发区"中心，车头朝东 |
| 里程计原点 | 出生点 | 靠 `<odometry_source>0</odometry_source>` 实现 |
| 出口门洞 | 世界系 x = 3.30，y ∈ [2.64, 3.30] | 东墙第 4 行 |
| 出迷宫门限 `exit_x` | 3.75 m（里程计系） | = 3.30 − (−0.33) + 0.12，驶出洞口约 12 cm 再停 |

**控制器内部格坐标**：以出发区为中心 (0,0)，入口格为 (1,0)，故"决策 14 格"对应格序列
`(1,0)E → (2,0)E → (2,1)N → (1,1)W → (1,2)N → (2,2)E → (2,3)N → (1,3)W → (1,4)N → (2,4)E → (3,4)E → (4,4)E → (5,4)E → (6,4)E`。

## 3. 感知：把 360 点压成三个距离

```python
def scan_zones(ranges, angle_min, angle_inc, half_deg=12.0, ...):
    # 对前/左/右/后四个扇区分别取限定角度内、去掉 inf 后的最小距离
```

三个要点：

1. **必须过滤 `inf`**：超量程方向返回 `inf`，不过滤的话 `min()` 永远是 `inf`。
2. **扇区取窄（±12°）**：边缘射线打到侧墙的距离是 `0.30 / sin α`，35° 时只有 0.52 m，会把侧墙当障碍。
3. **格心采样**：车对齐到格心、朝向精确到 90° 时才采样，此时窄扇区既准又稳。

实测读数（出发区中心）：前 1.48 / 左 0.27 / 右 0.28 / 后 0.28 m。

## 4. 决策：左手法则状态机

### 4.1 适用条件

左手法则保证到达出口的前提是**迷宫连通且无环**：贴左墙走等价于沿左边界做深度优先遍历，出口在边界上，必然被遍历到。

本仓库迷宫由迭代 DFS 生成，通路数 = 格子数 − 1（25 格 / 24 通路），是严格的生成树，`gen_maze_world --check` 会自动验证这一点。

### 4.2 状态与转移

| 当前状态 | 转移条件 | 下一状态 | 输出 |
| --- | --- | --- | --- |
| `DECIDE` | 停车稳定 0.30 s 后完成决策 | `TURN` / `ADVANCE` | 目标航向、目标格心 |
| `TURN` | \|航向误差\| < 0.035 rad（或超时 25 s） | `ADVANCE` | ω |
| `ADVANCE` | 到格心（距离 < 0.02 m 或越过目标平面） | `DECIDE` | v, ω |
| 任意 | 里程计 x > `exit_x` | `ARRIVED` | v = ω = 0 |

### 4.3 决策优先级

| 条件（阈值 0.55 m） | 决策 |
| --- | --- |
| `left > 0.55` | 左转 90° |
| `left ≤ 0.55` 且 `front > 0.55` | 直行 |
| 前两者不满足、`right > 0.55` | 右转 90° |
| 三面都 ≤ 0.55 | 掉头 180° |

阈值依据：格心到本格边界墙 0.33 m，到下一格远处的墙 ≥ 0.96 m，0.55 落在中间，两侧各留 0.2 m 以上余量。

## 5. 控制

### 5.1 转向（TURN）

```python
err  = norm_angle(target_yaw - yaw)      # 归一化到 [-π, π)
omega = clamp(kp_turn * err, ±w_turn_max) # kp_turn=2.2, w_turn_max=1.00
```

误差归一化不可省：否则在 ±180° 边界会出现"目标 +179°、当前 −179°，误算成 −358°"而原地疯转。

### 5.2 直行（ADVANCE）

```python
v = clamp(kp_dist * dist_to_target_center, v_min, v_nom)   # 0.05 ~ 0.18 m/s
omega = heading_hold(err_yaw) + k_center * (left - right)   # 侧墙居中
```

`left − right` 作为居中修正项：左边更近（left 小）则该项为负，车向右修，反之向左修；只在两侧都有墙时生效；`k_center` 过大造成蛇形，过小压不住偏移（默认 0.80）。

### 5.3 点到点 P 控制（`P2PController`）

两段式：先原地对准航向（`|α| > 0.55 rad` 时 v = 0），再边走边修：

```
d = ||goal - p||,  α = norm(atan2(dy, dx) - yaw)
|α| > 0.55 → v = 0,      ω = kp_ang · α
|α| ≤ 0.55 → v = kp_d·d (≤ v_max), ω = kp_ang · α
```

若一开始就 `v = kp_d·d`，车会沿切线画大弧、最后绕着目标转圈——这是最典型的初学者 bug。

## 6. 物理参数为什么重要

三个"代码里看不出来、只在仿真里炸"的问题：

| 问题 | 根因 | 参数 |
| --- | --- | --- |
| 车头下栽 18.5°，雷达前向从 1.62 m 掉到 0.50 m | 质心投影落在"两轮 + 万向球"支撑三角形边界上 | 质心 `(x=-0.02, z=0.028)` |
| 不发指令车以 12 cm/s 往后爬 | 地面默认接触刚度 `kp=1e12` 与 1 ms 步长叠加，接触求解器持续抖动 | world `<surface>`：`kp=1e6, kd=100`；轮子 `kd` 必须同值 |
| 里程计等于世界坐标，格心全错 | 差速插件默认用世界位姿当里程计 | `<odometry_source>0</odometry_source>` |

## 7. 关键参数总表

| 参数 | 默认 | 位置 | 作用 |
| --- | --- | --- | --- |
| `pitch` | 0.66 | `wall_follower` | 格距，必须与 world 一致 |
| `wall_thresh` | 0.55 | `wall_follower` | 判断"有墙"的距离阈值 |
| `v_nom` / `v_min` | 0.18 / 0.05 | `wall_follower` | 直行速度上下限 |
| `kp_turn` / `w_turn_max` | 2.2 / 1.00 | `wall_follower` | 转向角速度环 |
| `k_center` | 0.80 | `wall_follower` | 走廊居中修正强度 |
| `turn_tol` | 0.035 | `wall_follower` | 转角到位容差（rad） |
| `exit_x` | 3.75 | `wall_follower` | 出迷宫门限（里程计系） |
| `half_deg` | 12.0 | `scan_zones` | 前方扇区半宽 |
| `kp_lin` / `kp_ang` | 0.8 / 1.8 | `p2p_control` | 位置环 / 角度环增益 |
| `d_stop` / `d_slow` | 0.45 / 0.90 | `reactive_avoid` | 避障急停 / 减速距离 |

调参顺序建议：先 `wall_thresh`（保证决策对）→ 再 `v_nom`（保证稳）→ 最后 `k_center` / `kp_turn`（保证漂亮）。**一次只改一个参数。**
